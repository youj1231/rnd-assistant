소개 · 개인정보처리방침 · 이용 약관

대상

업무비서는 개발자 본인만 사용하는 개인용 앱입니다. 다른 사람의 정보는 받지 않습니다.

사용하는 Google 데이터

  • Google 캘린더: 캘린더 목록, 일정 조회·추가·수정·삭제
  • Google Tasks: 할 일 목록 조회·추가·수정·완료

처리와 보관

데이터는 사용자 본인의 PC에서만 처리합니다. 로그인 토큰은 그 PC에만 저장하며, 데이터를 판매하거나 광고에 쓰거나 다른 사람에게 넘기지 않습니다.

Google API 서비스 사용자 데이터 정책

Google API에서 받은 정보의 사용과 전송은 Limited Use 요구 사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

연결 해제

언제든지 Google 계정의 연결된 앱에서 접근 권한을 철회할 수 있습니다.
